Privacy Policy

Last updated: 13 October 2026

Short version: we collect no personal data, we set no cookies, and the app sends nothing anywhere.

The app

ScreenCraft is a desktop application that runs entirely on your device. It has no accounts, no telemetry, no crash reporting and no cloud features. Recordings, edits, captions and exports stay on your computer. The only network activity the app can perform is an optional, user-initiated download of a speech-recognition model (see below).

This website

This website is hosted on Cloudflare. We use Cloudflare Web Analytics, a privacy-focused service that provides aggregate traffic statistics (page views, referrers, country, browser and device type). It does not use cookies or local storage, does not fingerprint visitors, and does not track you across sites. We cannot identify individual visitors. Cloudflare also processes ordinary server logs (such as IP addresses) to deliver and secure the site, as described in the Cloudflare Privacy Policy.

We do not run advertising, social-media trackers, or embedded third-party widgets. The site loads no external fonts or scripts.

Downloads

Installers are served from GitHub. GitHub may process your IP address when you download; see the GitHub Privacy Statement.

Optional model download

If you use on-device captions, the app downloads a Whisper model file from Hugging Face the first time. That request is made directly from your device to Hugging Face, whose privacy policy applies. No audio or project data is sent.

Your rights

Because we hold no personal data about you, there is nothing to access, correct or delete. If you contact us (for example by opening a GitHub issue), the content you submit is handled by GitHub under its terms.

Children

The site and app are not directed at children and we do not knowingly collect any personal information.

Changes

If this policy changes, the date above will be updated and the change recorded in the public repository history.
