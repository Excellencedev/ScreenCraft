Projects and files

Every recording is a folder, and everything you change is stored beside the original footage.

Where they are

Projects live in ~/ScreenCraft Projects on macOS and %USERPROFILE%\ScreenCraft Projects on Windows. Each is a .screencraft folder containing the screen video, optional camera and microphone files, an input log and a project.json.

Non-destructive

Edits are saved as data in project.json. The recorded footage is never modified, so you can always return to the raw recording.

Saving

Changes stay in memory until you save. An asterisk in the title shows unsaved edits, and closing the window asks what to do with them.

Disk space

The preview proxy is large for long recordings (roughly 2 to 3 MB per second). Delete the proxy-* files in a project folder to reclaim space; they are rebuilt when needed.

Sharing a project

Copy the whole .screencraft folder. Note that it contains your recording and any camera footage.
