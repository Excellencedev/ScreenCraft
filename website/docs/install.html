Install

macOS

  1. Download screencraft_0_4_0.dmg, open it, and drag the app to Applications.
  2. The app is not notarized, so macOS blocks it the first time. Open System Settings → Privacy & Security, scroll down, click Open Anyway next to ScreenCraft, then confirm. (Or run xattr -dr com.apple.quarantine /Applications/ScreenCraft.app in Terminal.)
  3. Grant Screen Recording in System Settings → Privacy & Security, then relaunch. Microphone, Camera and Accessibility are optional and only requested for those features.

Windows

  1. Run screencraft_0_4_0.exe (per-user install, no administrator rights).
  2. If SmartScreen warns about an unsigned app, choose More info → Run anyway.

Build from source

Install Rust (stable) and run:

git clone https://github.com/MarshallNickolauson/ScreenCraft
cd ScreenCraft
./scripts/bundle.sh --install     # macOS
scripts\build-windows.ps1         # Windows
