Windows notes

ScreenCraft is one native application on Windows, the same as on macOS. Capture (DXGI), audio (WASAPI) and H.264 (Media Foundation, the operating system's own licensed codec) all use Windows-native APIs.

Requirements

  • Windows 10 version 1903 or later, or Windows 11.
  • A GPU with up-to-date drivers (ScreenCraft draws with Direct3D 12 or Vulkan). Nothing else to install: there is no web runtime.

Installer

The installer is per user, needs no administrator rights, and puts the app in %LOCALAPPDATA%\Programs\ScreenCraft. It is unsigned, so SmartScreen may warn: choose More info, then Run anyway.

Shortcuts

Use Ctrl where this documentation says Cmd. Start and stop recording with Ctrl Shift 2.

Known limits

  • The Windows build has had less testing than macOS.
