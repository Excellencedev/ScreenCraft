Windows notes

The Windows build shares the editor and core with macOS. Capture, decoding and encoding use Windows-native APIs.

Requirements

  • Windows 10 version 1903 or later, or Windows 11.
  • The Edge WebView2 runtime. The installer adds it if it is missing.

Installer

The installer is per user, needs no administrator rights, and puts the app in %LOCALAPPDATA%\Programs\ScreenCraft. It is unsigned, so SmartScreen may warn: choose More info, then Run anyway.

Shortcuts

Use Ctrl where this documentation says Cmd. Start and stop recording with Ctrl Shift 2.

Known limits

  • The Windows port has had less testing than macOS.
  • There is no standalone compressor yet.
