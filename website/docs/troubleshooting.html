Troubleshooting

The recording is black / empty (macOS)

Grant Screen Recording permission in System Settings → Privacy & Security and relaunch ScreenCraft.

Music sounds muffled or the recording is tinny with Bluetooth headphones

This happens when anything opens the headphones' microphone: the headset switches from stereo to a phone-call profile (16 kHz, mono), and so does everything it plays and records. ScreenCraft avoids it by using your Mac's built-in microphone instead and keeping the headphones for listening only. In the Microphone menu, pick the built-in microphone (it is marked as recommended when Bluetooth headphones are connected). If you choose the headset's own microphone on purpose, expect call-quality audio. A separate USB or wired microphone works too.

Keys are not shown

Grant Accessibility (macOS) or run without a blocking security tool (Windows).

Export seems stuck

Cancel and retry; ScreenCraft falls back to the software encoder automatically after a stall. Report persistent issues on GitHub with your OS and recording size.
