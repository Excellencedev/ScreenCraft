Captions

ScreenCraft can transcribe your recording's audio on your own computer using whisper.cpp, an open-source implementation of OpenAI's Whisper speech-recognition model. No audio is sent anywhere.

How it works

  1. Open the Captions panel and choose Generate captions.
  2. The first time, ScreenCraft downloads the Whisper model you pick (78 MB for tiny, 148 MB for base, 488 MB for small) from Hugging Face. This is the only network request the feature makes. The model is cached locally.
  3. Captions appear on the caption track. Edit the text and timing freely, change the style, or export an SRT.
