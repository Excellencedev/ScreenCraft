FAQ

Is it really free?

Yes. MIT licensed, no account, no watermark, no paid tier.

Does it use AI?

Only for the optional caption feature, which runs the open-source Whisper model locally on your machine.

Is it affiliated with Screen Studio?

No. ScreenCraft is an independent project and contains none of that product's code or assets.

Does it work on Linux?

Not yet.

Why does my OS warn me?

The builds are not code-signed by a paid certificate. See the install guide.
