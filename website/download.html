Download ScreenCraft

A free, open-source screen recorder and editor. No account, no watermark, no subscription. Version 0.2.0.

macOS

Apple Silicon and Intel · macOS 14 or later recommended · .dmg
Download for macOS
  1. Open the downloaded ScreenCraft.dmg and drag ScreenCraft to Applications.
  2. The app is ad-hoc signed, not notarized. On first launch, right-click it and choose Open, then confirm.
  3. Grant Screen Recording (and Microphone, Camera, Accessibility for key display) when asked, then relaunch.

Windows

Windows 10 (1903+) or 11 · 64-bit · .exe installer
Download for Windows
  1. Run ScreenCraft-Setup.exe. It installs per user and needs no administrator rights.
  2. The installer is unsigned, so SmartScreen may warn. Choose More info → Run anyway.
  3. The Edge WebView2 runtime is installed automatically if missing.
Early alpha. The Windows build was ported from macOS and has had less testing. Please report issues.
Prefer to build it yourself? ScreenCraft is MIT licensed — see the install guide for building from source. Source and all releases: GitHub.
